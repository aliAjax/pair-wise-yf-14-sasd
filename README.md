# 追光校对台（夜戏排练叠光校对）

排练夜戏时多束追光会叠在演员身上，现场只能临时关灯。本工具把灯位与 Cue
预置好，在触发前先做一次“叠光校对”：把覆盖同一落点的灯具亮度相加，超过
100% 就拦下该 Cue，停在当前场景，标出超限落点与灯具，原场景不动；调小灯具
亮度或光斑半径后只重算引用它的 Cue。

## 规则

- **灯具**：舞台坐标 (x, y)、光斑半径、亮度（%）。
- **Cue**：若干落点 + 参与灯具。
- **校对判定**：对每个落点，累加所有“光斑覆盖该落点”的参与灯具亮度；
  任一落点合计 > 100%，该 Cue 标记为「超限拦截」，不可触发。没有任何光斑
  覆盖的落点标记为「暗点」警告，但不拦截。
- **触发**：只有校对通过（或仅有暗点警告）的 Cue 可以触发并成为当前场景；
  超限时点击试触发只会出现拦截条，当前场景保持不变。
- **增量重算**：改灯具位置/半径/亮度 → 通过“灯具→Cue”反向索引，只重新
  校对引用该灯具的 Cue；改 Cue 的落点或参与灯具 → 只重算该 Cue；改名称、
  备注不触发重算。底部状态栏显示最近一次重算涉及的 Cue。

## 分层维护

- `src/data/`：类型、预置数据、localStorage 读写（数据层）
- `src/logic/`：覆盖几何、单 Cue 校对、引用索引与增量重算（判定层，纯函数）
- `src/components/`、`src/App.tsx`：舞台图、灯具调节、Cue 序列（页面层）

数据保存在浏览器 localStorage，校对结果仅存内存、刷新后重新计算，不上传服务器。
